# 五级双工质水源热泵：结构素材卡

文字许可：CC BY 4.0。状态：可复用结构描述，非默认参数、额定设备包或工程验收证据。

## 构型与系统边界

五个独立制冷剂循环，每级为 `EVAP_i → COMP_i → COND_i → VALVE_i → EVAP_i`。每级包含一台蒸发器、一台压缩机、一台冷凝器及一台节流阀，共20台核心单元。需要的分合流器按实际水路另列，不能把20台核心单元误当所有流程块数量。

双工质按循环隔离。例如低温四级可选R134a、高温级可选R245fa，但这只是该类素材的组分组织，实际选型仍需本项目物性、临界区、压力、环境与设备适用性核查。不得连接不同工质循环的物流以获得所谓“五级串联”。

热网水：`HW0 → COND1 → COND2 → COND3 → COND4 → COND5 → HW5`。第一级至第五级依水路服务顺序编号；编号不自行证明每级温升、负荷或压缩比。

源水的两种独立组织：

- 逐级串联：`CW0 → EVAP5 → EVAP4 → EVAP3 → EVAP2 → EVAP1 → CWOUT`。
- 带分合流的串联分组：`CW0 → EVAP5 → SPL_A → (EVAP3 ∥ EVAP4) → MIX_A → SPL_B → (EVAP1 ∥ EVAP2) → MIX_B → CWOUT`。

并联分支只有在真实系统要求和流量/能量依据下采用；这两种组织不是任意可互换的等价图。串联总管上的流股穿越另一根线也不代表物理连接，接点须由实际分合流对象确认。

## Aspen落地与参数交接

每个HeatX明确制冷剂侧/水侧和进出口对应角色，按新项目物性分配两侧方法。压缩机指定的效率口径、机械/电机损耗口径分开，节流机构检查等焓。稳态循环必须有合法循环库存/循环量规格与初值，不把未连接的四段开环图冒充闭式循环。

工况合同至少包含：两侧水的入口温压与流量；热水目标与各级负荷分配；每级蒸发/冷凝压力或相应温度依据；吸气过热与液体出口过冷状态；压缩机效率定义；两侧压降；Design/Rating/Simulation选择及其自由度。若设备额定尺寸/UA尚缺，明确是设计计算，不能声称既有设备两工况均通过额定。

总供热、蒸发吸热和压缩功以同一边界守恒。制冷剂功率、轴功和系统电功率的COP分开；水泵/电机/辅助设备若未计入，不能把制冷剂侧COP称为系统电耗实测COP。原表的单位、是否单台/双台、工况与功率定义先对齐，再比较。

压缩机理论等熵参考与实际不可逆压缩路径分别检查。相态设置不作为通用消错开关；不能默认复制某个NPHASE、过热度或效率以追目标COP。换热器不仅核端点，还核全程T–Q与最小温差；具体门槛由当前合同给出。

## 图面与素材复用

适合纵向五层表示：每级蒸发器左、冷凝器右、压缩机下、阀门上，水路在两侧分开走。它是表达方案，不是工艺约束；真实端口、分支和压力路径优先。原生图采用[排布工具与接口](../scripts/aspen-native-layout/README.md)；外部图逐流股对应同次真实模型，ImageGen只能辅助表达，错误管线须修正后再用于说明书。

本地素材的复用单位是“构型＋接口＋参数来源＋状态＋模型身份”，不是单张漂亮PFD。新工况应复制保护候选并重新冻结参数、运行和检查；不能把旧结果、面积、效率、压降、收敛或验收状态移给新案。

# Public tool-maintenance scope

This directory's allowlisted public files implement a newly requested local
tool catalog, invocation planning and offline file checks. They do not copy
project automation, model equations, controller settings, case results or
repair traces. No engineering experience is submitted or admitted by this
tool-maintenance change.

Public allowlist: `toolpack.py`, `tool_catalog.json`, `README.md`, `SKILL.md`,
`local_settings.example.json`, `LICENSE`, `PUBLIC_SCOPE.md`, and
`tests/test_toolpack.py`, plus a generated `PUBLIC_MANIFEST.json` recording
these exact public bytes. Private machine settings, review receipts, case
archives, project sources and native artifacts are excluded.

The history bridge delegates to the caller's installed operations evidence
owner. No parser is vendored or reimplemented. `manifest` checks listed bytes;
`grid` checks the caller's explicit CSV grid. Neither determines engineering
acceptance, publishes telemetry, starts services or alters tolerances.

The tests exercise synthetic offline code behavior. They are not native
Aspen runs, generalization evidence or a substitute for the experience inbox's
admission protocol. Source/version identity and test results are reported
separately from any engineering claim.

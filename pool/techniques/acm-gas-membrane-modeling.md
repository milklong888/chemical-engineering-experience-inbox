# ACM气体膜模型：量定义、流程接入与工况研究

类型：普通方法参考；priority：normal。本文依据公开文献与已有操作规则整理，不是某个项目的工程成功记录，不申请正式inbox准入，不设置默认材料、工况、容差或模型参数。文字许可沿用仓库CC BY 4.0。

## 1. 先区分材料试验与流程算例

把膜材料身份、有效选择层厚度、渗透系数或透过度、气体组成、温度、两侧压力及其基准分别列明来源。湿膜刮刀间隙不能直接当作干燥后的选择层厚度，背景页出现的聚合物名称也不能直接认作试验样品。

来源缺值、单位冲突或样品对应不明时保留缺口。采用另一种材料的公开参数建立软件基准，须同时更改算例身份与适用体系，不能据此宣称原材料性能得到预测或验证。方程实现、文献数值复现、实验验证和文件可移植性是不同结论。

## 2. 先统一量定义，再写传质方程

在一致单位下，透过度为材料渗透系数与选择层厚度之比。Barrer及GPU的定义另据DOE/NETL手册[3]，其STP为0 ℃、1 atm；不能把下面的GPU换算声称为Rodrigues原文给出的定义。使用Barrer及μm时：

```text
Π_i[GPU] = P_i[Barrer] / δ[μm]
1 GPU ≈ 1.2047×10⁻⁴ kmol/(m²·h·bar)
j_i,k = Q_i (p̄_H,i,k − p_L y_i,k)
q_i,k = A_k j_i,k
```

这里Q为以kmol/(m²·h·bar)表示的透过度，j为单位面积通量，q为单元组分透过流量。程序变量即使命名为J，也要从定义、单位与方程检查它是否已乘面积。GPU不是通量单位；不能将单元流量直接放到通量坐标轴上。

压力推动力必须使用两侧组分的绝对分压。理想选择性`P_i/P_j`与混合气分离因子`(y_i/y_j)/(z_i/z_j)`分别命名，后式z为进料、y为透过出口的摩尔分数。出口纯度与回收率也分别计算；进料中不存在的组分，其回收率应标不适用，不能以程序占位零当作测得结果。

## 3. 流动组织是模型条件

Rodrigues的Model 2提供了膜面积离散、并流累积透过物流的建模参考[1]。在该组织下，第k格低压侧组成由上游透过流与本格新增透过量共同决定，不能未经说明替换为每格独立汇流，也不能在所有单元中固定采用最终透过气组成。

每格联立两侧组分衡算；采用高压侧组分分压对数平均时，要处理相邻分压相等的极限及缺失组分边界。是否使用理想分压、逸度、压力依赖透过度、压降或非等温模型，应由当前来源和适用范围确定。上述简化不是所有膜组件的默认物理条件。

**源内核查提示：** 2009正文式(27)及2010式(6)将局部通量写为累积透过组分流除以单元面积，与附录递推需要区分。按2009附录10.3.2整理时，应使用`q_i,k = V_k y_i,k − V_(k−1) y_i,k−1`作为单格新增透过量，再除以A_k得到局部通量。附录变量注释与正文术语也不能替代递推、边界和量纲的交叉核对。

## 4. ACM接入与原生灵敏度分别验证

先在ACM检查方程、自由度、端口、输入规格及单位，再导出适配目标版本的模型包，在Aspen Plus中部署并连接进料、截留物和透过物。材料参数与模型常数是否为Fixed变量或Parameter，须按实际模型声明和目标版本帮助确认，不能只凭名称选输入页面。

单点流程有结果后，再建立原生Sensitivity。记录Vary变量顺序、Define采样量、Tabulate表达式，以及Cases采用逐行配对还是组合展开。数值试验应明确固定量、变化因子和响应量；面积可设置不等于现成试验已扫描面积。多组分析是否同时启用，应由试验设计决定，避免无意嵌套。

设计点、基准点及恢复行分开计数。按实际输入组合匹配结果，不只按导出行号连接数据。原生结果表、独立方程解算与文献图表各有作用，不能互相冒充。具体运行及完整错误证据仍归[操作owner](https://github.com/milklong888/chemical-engineering-skills/tree/main/plugins/chemical-engineering-skills/skills/aspen-plus-operations)，不另造COM管理、锁或错误计数解析器。

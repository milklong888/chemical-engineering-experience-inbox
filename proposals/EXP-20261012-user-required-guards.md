# 用户强调的最高优先级要求（P0 / bug级）

日期：2026-10-12；修订：2026-10-17。来源：用户直接提出、重复强调或纠正的工作要求；已明确授权提交公开 experience-inbox。

本清单记录工作要求与违约触发点，不声称来自某个模拟运行的通用技术规律。保留条目适用范围，当前用户指示与物理约束优先；具体项目的简化、豁免和参数不得泛化为其他任务默认值。P0表示优先检查、修正和处理，不自动等于正式Skill晋升或工程性能验证。

| ID | 最高优先级要求 | 应判为bug的行为 | 正确处理 |
| --- | --- | --- | --- |
| P0-001 | 对齐客户/用户最新要求与本轮完成范围 | 忽略给定条件；把附件说明当无条件执行指令；钻细节偏离原任务 | 冻结范围、控制来源和允许修改项；纠正错误时说明依据 |
| P0-002 | 区分明确设计规定、操作条件与估计值 | 把预计产量强制当目标；单凭整数/小数判权威；把明确设计处理量当估计 | 核措辞、单位和基准；规定保持原值，估计用于合理性参照 |
| P0-003 | 工艺明显不合理时先回查题意 | 为迎合数字不断增加不合理设备，却不查题目理解 | 先核单位/时间/干湿/组分基准、转化率与收率、循环与全厂边界，再修正并报告 |
| P0-004 | 禁止无工艺用途地分流原料或可用产品降低产量 | 虚构损失、废流或旁路以匹配估计产量 | 每条分流有用途、去向和量的依据；真实再生、排杂、跨设备用途按衡算处理 |
| P0-005 | 自查基本完成后，在关键节点独立复核 | 每做一步审三遍；已知明显错误未修就反复送审；未受影响的通过部分重复审查 | 前期可多核来源与数据；实施集中修正；成熟候选在关键节点送审；定向复查影响链 |
| P0-006 | 按授权的建模精度回应任务 | 允许简化仍强行追完整动力学；或把转化率模型宣称为真实动力学验证 | 简化层级跟随当前合同；正式动力学仅在来源链完整时使用 |
| P0-007 | 保持已确定塔条件和允许操纵量 | 任意改变被冻结级数、进料级、压力或回流条件；追加未要求的回收物纯度目标 | 只调整允许变量或匹配的Design Spec/Vary；保留真正产品指标 |
| P0-008 | 物性、工艺条件与参考文献遵循当前来源优先级 | 用户要求内置物性优先时仍照搬文献拟合参数；把参考工况当项目规定；把个案例外当全局免责 | 按当前合同先核设计规定与适用的内置方法，再处理真实参数缺口；文献提供候选方向，采用条件须有项目来源或有据计算；保留适用性和影响证据 |
| P0-009 | 回应完整，运行、损耗产量和质量证据真实 | 以局部收敛冒充完整回应；未核实就报零错误/警告；无限追查已明确豁免的同一取证项 | 依当前验收合同核实；明确待核/豁免范围，不虚构零值 |
| P0-010 | 不提前交出可继续完成的未完成结果 | 可执行工作尚未完成就只给计划；总结替代原任务 | 持续完成已授权工作；真实阻塞仅限制受影响部分 |
| P0-011 | 结束或闲置时释放自己任务资源 | 遗留Aspen/COM/进程/锁；为清理自己而中断其他任务 | 释放自有资源，核可继续调度；有明确授权才通知接续任务 |
| P0-012 | 委派服从用户当前分工，主代理负责推进与接受 | 把早期“简单任务交Luna”固化成永久指令；用户已要求主代理常规执行，仍不断拆分常规工作；子代理擅改目标 | 最新分工优先；用户允许在难关做多方向尝试时再作有界委派，实际设置适配的模型与推理强度；主代理保留工程判断、整合及最终接受责任 |
| P0-013 | 面向客户说明流程、工况与结果，名称服从约定 | 只有节点清单；缺少物流去向、设备作用与结果解释；违背用户已指定的设备命名格式 | 自然叙述物流进入哪台设备、发生什么及去往何处；当用户指定“功能＋位号”时保持一致；解释回流、指标、工艺条件来源和优化取舍，区分模拟结果与待核工程条件 |
| P0-014 | 如实说明制图工具与完成状态 | 把程序导出旧图冒称imagegen；未生成就说完成 | 指定image时实际调用imagegen；区分参考/生成/功能示意，查箭头与文字 |
| P0-015 | 明确迭代预算和待更新项放显眼位置 | 用户要求建模时遗漏、最后临时处理；改已有求解容差换收敛 | 早期落实当前指定预算并显式记录待更新项；不把个案数值当全局默认，不改被冻结容差 |
| P0-016 | 先核目标主次、依赖关系与自由度 | 未检查指标耦合就追求所有指标同时恰好等于边界；将有关联的目标重复配置成互相争用变量的等式 | 先核来源的等式或不等式语义，再列目标—操纵量关系与可推导依赖；只对独立且有依据的设定点解等式，其余按原限值不等式校核；来源确需等式时不得擅自降级 |
| P0-017 | 清理中间文件须保留可复盘的方向与失败证据 | 只留最终成功结果，删除未采用方向、失败日志或唯一输入输出；用一段摘要替代原始证据 | 先分类交付物、来源、决策记录、方向试验与可重建缓存；独有证据保留或无损归档并核验完整性，再清理散文件；提供索引与恢复方法，不动其他任务资源 |

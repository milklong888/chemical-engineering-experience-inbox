# 双效各构型：怎样接、哪些不能接、何时还不能判定

读取要求：先完整读取本卡；若工具实际报告输出截断，分段补读缺失内容，看到开头和结尾不能证明中间已读。正文出现`truncated`一词不等于工具发生截断。按题设选构型，再核相应变体，不能只套第1节全冷凝骨架。

## 0. 先分清三个互相组合的维度

- 进料安排：并联分料、指定HP底物流去LP、指定LP净底物流去HP等。
- LP再沸器：一次通过釜式平衡近似、自然循环热虹吸、强制循环等。
- 热服务表示：显式过程HeatX，或内置端器加热流/受支持的计算关系；还可有部分热集成和有据混合配置。

因此以下不是八种互斥标准流程。HP/LP仅指较高/较低压力角色，不表示原料进入先后，更不保证HP顶温度高于LP底温度。本文串联例子明确指定跨塔的是底部净物流，不把它当作所有文献中顺流/逆流的唯一定义。

`HX-DE`在热、冷两行均是**同一台HeatX**。H-IN/H-OUT、C-IN/C-OUT是本文的职责标签，不是未经核实的Aspen端口名。热侧/冷侧不自动等于壳程/管程。箭头是物料；`==热==>`只传递能量。

`V_HP`指从HP顶抽出的、尚未分为回流与净产品的总顶汽；`R_HP`是液体回流；`D_HP`是净顶采出；`V_LP`是返汽；`B_LP`是净底采出。gross循环量不能算成净产量。

## 1. 并联进料＋HP全冷凝＋LP一次通过釜式平衡近似

适用前提：选定一次通过的外部平衡级近似；热侧能在给定压力下充分冷凝为可分流的液体；未出现需要另行处理的第二液相。工况未核时，这些是条件，不是结论。

```text
F → FSPLIT-F ┬→ F_HP → 所需进料调压 → HP RadFrac进料位置
             └→ F_LP → 所需进料调压 → LP RadFrac进料位置

HP RadFrac顶 V_HP → HX-DE.H-IN
HX-DE.H-OUT（液体）→ FSPLIT-R ┬→ R_HP → 所需液体压头恢复 → HP顶部液体返回位置
                             └→ D_HP → 指定净产品边界

LP RadFrac底部总抽液 L_LP → HX-DE.C-IN
HX-DE.C-OUT（两相）→ FLASH2-K
                         ├→ V_LP → LP下部汽相返回位置
                         └→ B_LP → 指定净底产品边界

HP内部再沸器 ← 外部公用工程供热；HP净底 B_HP → 产品边界
LP内部冷凝器：LP顶汽冷凝，内部回流回LP，D_LP → 产品边界
```

选定本完整外置替换时：HP取消内置冷凝服务、保留内置再沸服务；LP取消内置再沸服务、保留内置冷凝服务。不能仅把对应内置负荷设为零就声称完成端器替换；应核实际配置、有效级数、塔顶/塔底边界及所有返回位置。删除内置端器可能改变级号，不能盲用旧级号或把旧再沸级又完整计入一次。

FLASH2-K承担外置釜的平衡分相近似。若所有加热已在HX完成，应按真实入口焓、压力与约定压降做无额外供热的分相（例如适用的P、Q=0设定）；不能另钉一个温度，让FLASH2悄悄承担未记账的加热或冷却。它不证明真实釜体尺寸、停留量、液位控制或传热面积。

**本构型的具体禁则**

| ID | 不接受的接法/说法 | 正确替代或核验 |
|---|---|---|
| K01 | 内置冷凝器后的净馏出液D_HP直接当作V_HP接HX，再宣称已替代HP总冷凝服务 | 从实际总顶汽路径取热源；若只回收产品热量，独立命名其热服务 |
| K02 | HX热侧液体全部当产品，HP仍被描述为具有回流的精馏塔，却没有其他回流来源 | 本例明确FSPLIT-R和R_HP；若有其他合规回流来源或零回流设计，另列来源、职责与衡算 |
| K03 | HX冷侧全部当B_LP，同时声称它给LP提供返汽 | FLASH2-K汽相V_LP返塔，液相才是本例净底采出 |
| K04 | 从HX两相出口用普通FSPLIT“分出纯汽与纯液” | 用相平衡分离器，或另选两相回塔并由塔内承担分相的构型 |
| K05 | 将FLASH2-K全部液体返回、又没有任何LP净底出口或零底流设计说明 | 本例保留一个B_LP；若有别的合法采出，逐股列出职责及总账 |
| K06 | 从LP底和外置釜同时画两个同名B_LP，按同一个净产品各计一次 | 本例只设一处净采出；真实双采出需不同流股标识、各自去向和合并后的净采出总账，允许同属一个最终产品 |
| K07 | 凝液压力不足仍无条件直接回HP；FLASH2压力低于LP返回点还硬返汽 | 核各点压力、位差和压降；液体可有据配置回流泵/静压头，汽相须有真实可行压差路径 |
| K08 | 用“关内置端器”的口号替代真实接口及级数重映射 | 核软件配置、外置平衡级是否计一次、返回相态与所在级；不能编造COM路径 |

质量基准一致、无支路积累时，可用`V_HP = R_HP + D_HP`和`L_LP = V_LP + B_LP`查漏；有排气、旁路或额外采出时须显式加项。这些等式只查结构，不决定分配比例或产品纯度。

## 2. HP先受料，HP底部净物流去LP

保持第1节两侧换热、HP回流和LP返汽路径，仅替换进料与跨塔产品边界：

```text
F → 所需调压 → HP进料
HP净底中间物流 I_HL → 有据减压路径 → LP指定进料位置
全岛净出口：D_HP、D_LP、B_LP（以及明确存在的其他终端）
```

有据减压可由VALVE或能表示实际压降的其他合法路径承担，不能强制每案多放一台阀；降压后的闪蒸及进料焓要随真实状态计算。

- **S-HL01：** I_HL不是全岛最终B_HP，不能既计产品又全量进入LP。
- **S-HL02：** 不用“高压自己会流向低压”跳过两塔间压力差如何消耗、是否闪蒸及接收位置。
- **S-HL03：** HP净底跨塔进料与LP底部再沸抽液不是同一股；不要把I_HL直接冒名为HX冷侧的循环底液。
- **S-HL04：** 为使热负荷匹配而另外偷加原料分流会改变此构型，必须先更新授权和进料分配基准。

此处从HP送往LP的是底物流；若来源要求顶馏出跨塔，应另画其回流/净采出分配和接收任务，不改标签冒充本图。

## 3. LP先受料，LP外置釜净液去HP

同样保留第1节的换热、HP回流与LP返汽，仅改变进料和FLASH2-K液体去向：

```text
F → 所需调压 → LP进料
LP底部总抽液 → HX-DE冷侧 → FLASH2-K ┬→ 汽相V_LP → LP下部返回
                                    └→ 液相I_LH → PUMP-X → HP指定进料位置
全岛净出口：D_LP、D_HP、B_HP
```

- **S-LH01：** 低压釜液不能没有加压路径就进入更高压力HP进料口；泵出口需覆盖接收压力与沿程损失。等效供压必须有证据。
- **S-LH02：** 不把FLASH2-K的汽相接普通液体泵，也不在未核入口液态、有效汽蚀余量时宣称泵可用。
- **S-LH03：** I_LH是离开LP的净中间物流，不是全岛净底产品；计算产量不能重复计入。
- **S-LH04：** V_LP仍返回LP；不能把“送第二塔”的指令误用于汽液两相全部送HP，否则本图的LP返汽丢失。
- **S-LH05：** 固定HP/LP及此液相跨塔角色后，不添加与题设矛盾的“压力反过来时用阀”旁支充数。

## 4. LP自然循环热虹吸：两相回塔

HP热侧仍按第1节全冷凝＋分配回流；冷侧换为下面这一种从底部集液区取液的循环布置：

```text
LP底部集液区总抽液 → FSPLIT-B ┬→ B_LP → 净底产品边界
                              └→ CIRC-L → HX-DE.C-IN
HX-DE.C-OUT（两相）→ LP下部汽液返回/集液区
```

实际模型也可由受支持的独立液体侧线和底产品口承担分配，但必须列出真实接口；一股物料线不能在软件里无模块地变成两股。

- **TS01：** 本自然循环型式没有外部循环泵；不能暗加泵后继续把所得流量当作自然循环验证。
- **TS02：** 两相回流应到所选LP下部接收区，汽相向塔内上升、液体进入相关集液区；不能全作净产品，也不能送HP顶部。
- **TS03：** 不机械加一个外部FLASH2并把其液体全作净底产品，再声称仍是原来的两相回塔循环；这已改变分相与净采出位置。
- **TS04：** 不把“换热器画得低”当作循环成立的证据。需要液位、各段密度、位差和整个回路压降；无这些数据只能报热水力未核。
- **TS05：** 不把指定的循环流量视为自然循环计算结果。流程模拟中的给定流量/热量，还需独立核流动驱动力与负荷能否相容。

HTRI说明密度差驱动液体经过入口、再沸器和出口返回塔，并强调热与水力耦合；它支持这里的审查原则，不给本项目循环倍率或布置尺寸。[来源](https://www.htri.net/news/demystifying-thermosiphon-operation)

## 5. LP强制循环：液体泵在受热前

本例选择受热后两相回塔的强制循环形式：

```text
LP底部集液区总抽液 → FSPLIT-B ┬→ B_LP → 净底产品边界
                              └→ CIRC-L → PUMP-C → HX-DE.C-IN
HX-DE.C-OUT（两相）→ LP下部汽液返回/集液区
```

- **FC01：** 不把普通液体循环泵放在HX两相出口后，并直接称其入口满足要求；本例泵在液体受热前。
- **FC02：** 不遗漏B_LP，或又从两相返回线上未经分相取一个同名“底液产品”。
- **FC03：** 泵提供的是压头/轴功，不是替代HX所需热量的免费热源；轴功、循环流量、压降均应进账。
- **FC04：** 不用全流送产品来消除循环收敛问题；那会删除返汽及所选循环服务。
- **FC05：** 不把本例升格为唯一强制循环结构。若选择“加压液体在HX内不沸腾、降压后闪蒸”的型式，要补真实降压和分相/返回路径，另行审查。

## 6. HP部分冷凝或含不凝气

替换第1节热侧，冷侧可与已声明的釜式或循环型式组合：

```text
HP总顶汽 V_HP → HX-DE.H-IN
HX-DE.H-OUT（两相）→ FLASH2-H ┬→ VENT-H → 指定回收/尾气/真空系统边界
                             └→ 液体 → FSPLIT-R ┬→ R_HP → 所需液体供压 → HP顶部
                                                └→ D_HP → 净液体产品边界
```

- **PC01：** 不将HX热侧两相出口直接接FSPLIT，指定一个出口为纯气、另一个为纯液。
- **PC02：** VENT-H是带有组成和焓的真实物流，不能因“不是主产品”删掉；也不能默认全回HP而不查不凝气积累。
- **PC03：** 不把全顶汽量当液体回流量；液体回流来自分相后的液体库存/流量。
- **PC04：** FLASH2-H与LP的FLASH2-K是两台不同职责的分离器，不能将双方流股混入一个分离器以减少模块。
- **PC05：** 分离器若只承担分相，不能再次凭空降温供冷；需要进一步冷凝时设有明确公用工程的trim冷却。
- **PC06：** 气相出口可为合法净气体产品或处理边界，不强迫每股都返回；但不能无依据声明是无损排放。

包含该支路时，热侧总账为`V_HP = R_HP + D_HP + VENT-H`（无其他支路、同一质量基准）。FLASH2-H只是一种气液平衡分离表达；多液相或特定非平衡设备另选适用模型。

## 7. 内置端器＋热流/计算关系耦合

这是热负荷抽象，不是上面四物料口HX的替换图：

```text
HP总顶汽 → HP内部冷凝器 → 内部回流与净采出（必要时含气相出口）
HP内部冷凝器放出的可回收热 ==热==> LP内部再沸器
LP内部再沸器：塔内液体部分汽化，汽返回LP，净底液由LP产品口出
HP内部再沸器 ← 外部公用工程；LP内部冷凝器 → 外部冷却公用工程
```

用正的热量大小表示，忽略已另行说明的散热：

```text
Q_HP冷凝总量 = Q回收 + Q外部冷却
Q_LP再沸总量 = Q回收 + Q外部补热
```

这是物理记账，**不是**可直接照填的Aspen热流正负号语法。热端器负荷、接收规格和符号必须按目标版本核实；可用受支持的热流连接或经核实的规格/计算关系，但不能多个控制器同时写一个量。

- **Q01：** 不因有外部Heater就删掉内部再沸器；先看Heater处理的是过程液，还是热媒/公用工程。
- **Q02：** 不把一个Heater或一根热流称为已经有四物料口HeatX、已经核完温差或已有面积。
- **Q03：** 不将HP、LP过程物料用Mixer混合来传递这份热量；热流不带物料组分。
- **Q04：** 热媒Heater若实际建块，必须有热媒入口、出口及凝液回收/循环/终端；不能孤块占位。只做能量记账时明确不宣称已建实体热媒回路。
- **Q05：** 未找到直接热流端口，不足以断言只能改显式HeatX；先查版本支持的端器规格和计算关系。任何方式均需同次负荷闭合。
- **Q06：** 不同时把两个端器固定原负荷、固定Q回收、固定补热，又假定自由度一定足够。链接后需求可变化，应由合法独立规格求解。

内部端器配合公用工程侧Heater可为合法抽象；它与过程物料侧外置换热的区别有公开模拟讨论支持。[Luyben 2022](https://doi.org/10.1016/j.cep.2022.109068)

## 8. 部分热集成：先选清楚补热/补冷位置

在第1节**完整外置替换**骨架下，一种直接可审的串联trim布置是：

```text
HP总顶汽 → HX-DE热侧 → COOL-TRIM（需要时）→ 凝液分配或FLASH2-H → 回流/净采出
LP总抽液 → HX-DE冷侧 → HEAT-TRIM（需要时）→ FLASH2-K → 汽返LP / 液净采出
```

COOL-TRIM、HEAT-TRIM可按任务用Heater模型表示冷却和加热，分别列明负荷来源、压降与出口状态；它们不等于EDR。无相应剩余负荷时不为凑图添加。HP自身供热仍在HP再沸器，LP顶冷凝仍需冷却。

此变体覆盖第1节的相态假设：要求全冷凝的是**HX＋必要补冷构成的整条热侧链**，不要求共享HX出口已经全凝。若共享HX内已全凝，且没有后续降压再闪蒸等新增汽相过程，后置冷却只能承担有明确要求的进一步过冷，或负荷为零而不设置；不能再称它完成“剩余冷凝”。若有新增汽相及再冷凝服务，单独说明来源，不冒称共享HX遗留的未凝汽。只有整条链末端满足液体条件才直接进入液体FSPLIT；仍含气相时应有明确分相及气体出口。

补冷位置按需要处理的相态选择：若HX出口两相流还有待冷凝的汽，可在分相前补冷；若已经分相且要进一步回收气相中的可凝物，应处理气相支路，再安排凝液去向。不能把冷却器只接在分相器的液体出口后，却声称它冷凝了已从气体出口离开的蒸汽；液体后冷却只改变该液体支路的状态。

两股凝液合并前需核供压、相态和混合相容性。将Mixer改名为“多入口分配器”并不能消除不相容压力或混合问题；若改为分别分配、分别返回，须有真实可用的接口、各支路压力路径及整体衡算，不能编造软件端口作为逃避条件的替代。

- **PI01：** 不强迫HP全部冷凝热与LP全部再沸热天然相等。`Q回收`受源、汇和传热温位共同约束，剩余另有真实服务。
- **PI02：** 不把主HX和trim对同一股物流的同一段相变各算一次完整负荷；沿实际焓路径分账。
- **PI03：** 不在已经按完整外置方案画完抽出/返回之后，仅加一句“原内置端器补剩余Q”就认定混合方案成立。
- **PI04：** 内外端器并存并非绝对禁止。若另选混合配置，应列出每个抽出/返回口、内外相变职责、级数与热账，核实软件支持，再与原产品和边界比较。
- **PI05：** 不把产品热回收断言为无效，亦不在相态未知时一概称“只有显热”。其可有价值，但没有建立返汽服务就不能冒名为本图的LP再沸替换。
- **PI06：** 启动或低负荷时HP热源可能不足；补热/旁路/备用需有职责说明，但稳态箭头不证明动态控制已验。

## 9. 两侧逐口审查与语言限制

| 检查点 | 必须写清 | 不能用来蒙混的表述 |
|---|---|---|
| H-IN | 来源塔、抽出位置、相态、gross还是net | “高温物流进换热器” |
| H-OUT | 全冷凝/两相、分相职责、回流和净采出各去哪 | “冷凝后返回系统” |
| C-IN | 底部总抽液还是循环支路，取液和净采出位置 | “塔底产品去再沸”且又把它全计净产品 |
| C-OUT | 汽返塔、两相回塔或产品终端；由哪个模块分相 | “气液分开回去”但没有承担分相者 |
| 热侧回流 | R_HP回HP顶部的液体接收位置、供压条件 | “回流回塔”而不指哪塔、哪相 |
| 冷侧返汽 | V_LP回LP下部；或两相回指定集液区 | “回流蒸汽”混淆顶部液体回流与底部返汽 |
| 热服务 | HP塔外供热与HX热侧来源分别表述 | “HP的热源就是其顶汽冷凝” |
| 验证层级 | 结构可解释／条件待核／真实文件运行结果分别说 | “箭头闭合，所以双效可行且无警告” |

两侧之间只换热，不跨壁交换物料。在上述模板中，HX热侧不承担LP返汽，冷侧不承担HP回流；改变这一映射须另立跨塔物料路径、相态和分离依据。合法跨塔送料也可从某个HX出口出发，但它是一条独立物料边，不能仅因换热连接就自动跨塔，更不能借换热壁连通。

每个离开换热器的流股都应有职责，但合法产品、排气、排污、跨工段交接可以是岛边界终端；不要求全都接回本岛。未知出口不能仅改名“产品”过审。

温差判断须覆盖适用压力/组成下的换热过程，而非只看“HP”标签或两个入口温度。全段热曲线、相态、压降、换热能力及产品指标尚未核时，结论保持条件化。Aspen官方学习指南列有端器热曲线与Reboiler Wizard外置HeatX分析入口；该资料不提供本文端口名或跨版本实现保证。[官方指南，p11](https://www.aspentech.com/en/-/media/aspentech/home/cst-certification/aspen-plus-certification/at-05198_aspen-plus-dm-study-guide)

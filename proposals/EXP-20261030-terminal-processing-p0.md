# 出口流股不得无依据追加加工

产品、富余气、放空、废水、固废或公用工程回流达到已冻结出口边界后，默认直接出界。没有明确下游接收要求、产品交付指标、储运约束或本边界内必要的物理处理，不得追加调温、升压、减压、分流或混合操作。为统一出口温压、改善显示、消除警告或凑出某个数值而加工出口，判为流程建模bug，先撤回这项无依据设计，再按实际边界复核。

## P0-018：前置判断与交付阻断

- 拟新增出口处理块或改变出口条件之前，先给出实际服务对象、所需状态、源依据及当前设计合同；无依据时不创建该块。
- source/scaffold、工段接回、模型修复、拓扑变更及交付复核时，逐条追踪终端物流及其完整上游尾链。出口名称在白名单中，不豁免额外处理；不能通过改名、插入Mixer/FSplit或增加跳数避开检查。
- 必要处理按逐块物理目的核对。约定了真实储运压力的产品泵、确实发生冷凝的分水、边界内有依据的污染物处理，以及接回真实设备所需调节，可以保留；其条件、能量和排出物继续纳入同版核验。
- 单纯“自然压力不能升高”仅能约束必要设备的实现，不能反向制造没有接收需求的出口升压任务。检验器只能检查声明和当前拓扑；缺失实际依据是unknown/阻断，不冒充工程通过。

# 碱性电解模型：脱敏方法参考

作者：milklong（milklong888）。脚本采用MIT许可；方法说明采用CC BY 4.0。

状态：archive_reference / method_reference_only；不是 executed_success，不是收件、工程验收、默认检索或参数模板。learning_eligible、success_case_eligible、default_rule_eligible 均为 false。本目录不含工程运行结果、原模型源码、原始日志或项目参数默认值。

以下内容是受约束的核对方法，不能据此宣称某个模型已经成功：

- **出口焓**：分别读取真实阳极、阴极端口流量与焓，用各端口焓流之和核对能量。若出口可能两相，核对物性调用是否代表实际混相；不能将两股物料假想混合后的焓代替各出口焓流，也不能为弥补偏差重复加入反应热。修复前后须另核原电化学方程、单位、相态和源常数。
- **重启**：存档的收敛标志不证明新实例已初始化。区分非固定变量猜值与真实进料、固定规格；核对首次运行、无修改保存重开及扰动重启。无条件初始化是需逐模型验证的选择，不是通用补丁。
- **APP4类接口**：明确表观组分数组与原生组分列表映射，核对实际导出和自由度。局部数组映射不能证明全局电解质物性域已隔离，不能据零流量推断无物性查询，更不能猜补介电常数或其他缺数据。
- **广延聚合**：先声明每个变量的强度/广延分类；等同单元的强度量保持、广延量按显式单元数缩放。补水、反应进度、功率与热流须各有唯一记账责任，防止重复乘倍数。聚合候选须与显式实例同入口、同功率核对，不能外推到异质单元或设备容量。
- **raw bounds**：原始canonical上下限与显示单位分开保存。只有取得相同源类型的canonical基准后才比较raw值；不能因为显示WATT就把raw上下限当作W，也不能把初始化条数当并联倍数。导入时没有clipping消息不等于真实求解修复。
- **末端用途**：氢、氧出口应按接收工序要求核对压力、相态、含水、杂质及热负荷；循环流量不是槽液库存，流程计算不是供应商rating。压缩列合并还须保留逐级压力、冷凝液和末端冷却分离，比较同入口功耗及终端状态。

局部修复、整厂运行、严格交付和设备资格分别记账。局部检查通过不能移除上游放宽/未知谱系；剩余警告、非零残差和未建模事项必须保留，不能改名为成功案例。遇到来源不明参数或未知警告，先核版本绑定的原生资料，再查官方知识库，仍不足才查外部一手来源。

## 离线检查器

`scripts/acm_parallel_contract_audit.py` 只读取调用者JSON，标准库运行，不连接或启动ACM/Aspen，不改输入、不换单位、不读取工程输出。文档字符串定义输入契约。显式abs_tol/rel_tol按 `abs(actual-expected) <= abs_tol + rel_tol*abs(expected)` 判断；容差由调用者给出，不是工程验收阈值。raw_canonical还要求相同且非空的源basis标识；该标识由调用者负责取证，脚本不认证其真实性。

运行：`python scripts/acm_parallel_contract_audit.py input.json`。退出码0为所给JSON通过，1为数值不匹配，2为输入无效。运行合成测试：`python -m unittest discover -s tests -v`。合成数值只有测试用途，无工程参数意义；代码测试不能证明物理分类正确、原模型运行或工程验收。源码身份与测试范围见 `SOURCE_METADATA.json`。

同名、同单位不证明量的物理定义相同；变量分类、定义与canonical基准必须由调用者另行核实。重复JSON键、布尔数值、缺字段、非有限值及未分类变量一律拒绝。N=1是恒等契约。
